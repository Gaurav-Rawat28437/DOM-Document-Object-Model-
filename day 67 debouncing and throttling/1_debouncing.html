debouncing

  • Function runs only after user stops triggering event for some time.

Diffence

Feature Debouncing Throttling
Basic Idea Function runs after event stops for some time Function runs once in a fixed time interval
Execution Only the last event runs Runs continuously but with a limit
Event Calls Many events → 1 function call Many events → multiple limited calls
Use Case Search bar, API request Scroll, mouse move
Goal Reduce unnecessary calls Control execution rate
